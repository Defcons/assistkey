# docs

Working notes for developing AssistKey, kept together with the AI coding
assistant (Claude Code) that helps build it. You don't need any of this to use
or change the app.

- `KnowledgeBase.md`: how the app behaves and why.
- `ResearchJournal.md`: a dated log of changes, bugs and what was learned.
- `ToDo.md`: things that were deliberately put off.
- `Testing.md`: checks that still need a person to try them.

`OrientationMap.md` in the repo root is the short map of the code that goes with
these. The images here are the screenshots used in the main README.
